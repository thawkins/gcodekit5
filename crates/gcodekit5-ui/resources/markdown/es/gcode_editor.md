# Editor de G-code

El editor de G-code se utiliza para visualizar y editar el G-code antes de la transmisión.
Está integrado en el Control de Máquina encima de la consola.

## Funciones principales
- Cargar/guardar archivos de G-code
- Resaltado de sintaxis (cuando esté disponible)
- Preparar archivos para la transmisión
