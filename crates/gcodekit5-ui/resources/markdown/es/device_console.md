# Consola del dispositivo

La consola del dispositivo muestra las líneas sin procesar recibidas del controlador y los mensajes enviados por GCodeKit5.

## Contenido
- Eventos de conexión (conectado/desconectado)
- Cadenas de inicio (p. ej., `Grbl 1.2h ...`)
- Líneas de estado, respuestas (`ok`) y errores (`error:n`)

## Errores
Cuando una línea GRBL incluye `error:n`, la consola también mostrará el significado decodificado después del texto sin procesar.

## Consejos
- Use **Copiar** para copiar el contenido visible de la consola.
- Use **Borrar** para borrar la vista de la consola.
