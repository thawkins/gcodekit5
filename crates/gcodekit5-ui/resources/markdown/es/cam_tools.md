# Herramientas CAM

Las herramientas CAM proporcionan generadores y asistentes que crean G-code para tareas comunes.

## Herramientas
- [Creador de cajas con pestañas](help:tabbed_box_maker) — cajas con uniones dentadas
- [Generador de puzles](help:jigsaw_puzzle) — patrones de puzle
- [Grabador láser de imágenes](help:laser_image_engraver) — grabado rasterizado a partir de mapas de bits (diferente al que se genera en el diseñador)
- [Calculadora de velocidades y avances](help:speeds_feeds_calculator) — puntos de referencia de RPM/avance inicial
- [Planeado de Sufridera](help:spoilboard_surfacing) — Planear un tablero sufridera
- [Rejilla en la Sufridera](help:spoilboard_grid) — marcado/grabado de cuadrícula en la sufridera
