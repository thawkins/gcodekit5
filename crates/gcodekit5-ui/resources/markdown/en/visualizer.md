# Visualizer
<img src="../../help_images/visualizer_3d.png" alt="Visualizer_3d" width="1200">

The Visualizer displays a preview of the toolpaths and (optionally) the machine's work area limits.

The visualizer is 3D and has display controls in the upper right corner: Front, Side, Rear, Isometric, etc. It also includes controls for Snap to Drawing, Top View, Zoom + and -, Scroll Bar Display, and Orbit.

- Show/Hide Quick Moves
- Show/Hide Cutting Moves
- Show/Hide Tool
- Show/Hide Grid. The grid spacing can be defined.
- Show/Hide Machine Boundaries

- In the lower left corner are the Play/Pause/Stop buttons to start the tool movement simulation. There is a playback speed control with various speeds as needed.

This simulation can also be started via the File/Run menu.

- There is a Simulation dropdown menu with a checkbox that generates a 3D visualization of the material and the area being cut by the tool.

- "Inspector" dropdown menu with the bounds values ​​of the route
